# Simulate Application Memory Consumption

This Python script simulates how multiple applications can collectively consume a significant amount of RAM. It creates several large lists of strings, estimates their combined memory footprint, and explains how this contributes to a system's overall memory usage. This demonstrates why 16 GB RAM might feel insufficient due to hidden overheads like the OS and integrated graphics.

## Language

`python`

## How to Run

Save the code as `main.py`.
Run from your terminal: `python main.py`
